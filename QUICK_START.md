# ElaraPay - Quick Start Guide

## 🚀 Get Started in 2 Minutes

### Step 1: Open the App
1. Open `index.html` in your browser
2. Wait for splash screen (2 seconds)
3. You'll see the login screen

### Step 2: Create Account
1. Click "Create one" link
2. Fill in your details:
   - **Full Name**: Any name (e.g., "Adaeze Okafor")
   - **Email**: Any email (e.g., "you@example.com")
   - **Password**: 6+ characters
   - **Gender**: Choose one (sets your initial theme)
3. Click "Continue"

### Step 3: Set PIN
1. Enter a 4-digit PIN (e.g., 1234)
2. Confirm the same PIN
3. Account created! ✅

### Step 4: Explore
- **Home**: View balance, quick actions, transactions
- **Transfer**: Send money to other accounts
- **Pay**: Pay bills (airtime, data, cable TV, etc.)
- **Wealth**: Virtual card, savings goals, loans
- **Account**: Profile, themes, settings

## 💡 Quick Tips

### Send Money
1. Go to **Transfer** tab
2. Select a bank
3. Enter account number (10 digits)
4. Wait for name resolution
5. Enter amount
6. Enter PIN
7. Done! ✅

### Pay Bills
1. Go to **Pay** tab
2. Select category (Airtime, Data, etc.)
3. Choose a plan
4. Enter PIN
5. Done! ✅

### Change Theme
1. Go to **Account** tab
2. Scroll to "Appearance"
3. Tap any theme
4. Changes apply instantly ✅

### Add Money
1. Go to **Home** tab
2. Tap "Add Money" quick action
3. Select amount or enter custom
4. Enter PIN
5. Get 1% cashback! ✅

### Virtual Card
1. Go to **Wealth** tab
2. Tap card to reveal number
3. Flip card to see CVV
4. Tap "Copy Number" to copy
5. Tap "Regenerate" for new card

## 🆘 Troubleshooting

### App Won't Load
- Clear browser cache
- Refresh page (F5)
- Try different browser
- Check internet connection

### Can't Log In
- Check email spelling
- Check password (case-sensitive)
- Try signing up again
- Clear browser data

### PIN Not Working
- Make sure it's 4 digits
- No spaces or special characters
- Try again (3 attempts)
- Use biometric if enabled

### Offline Not Working
- App must be opened once online first
- Service Worker needs to cache
- Check browser supports PWA
- Try refreshing page

### Theme Not Changing
- Refresh page after selecting
- Check browser supports CSS variables
- Try different theme
- Clear cache and reload
